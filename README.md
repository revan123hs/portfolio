# Simon Gebru Portfolio

React + Vite + Tailwind CSS portfolio.

## Run in VS Code

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost address shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Main file

The portfolio UI is in `src/App.jsx`.
